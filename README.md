Key Features
	•	Decentralized AI Training: Each node trains models locally on private datasets.
	•	Data Privacy: Patient data never leaves the source; only encrypted model updates are shared.
	•	Blockchain-Enabled: Smart contracts manage model registry and federated learning updates.
	•	Modular Architecture: Frontend, backend, smart contracts, and deployment pipelines separated for scalability.
	•	Secure and Auditable: End-to-end encryption and blockchain provide transparency and trust.


    Structure
    	•	docs/ – Documentation including architecture, API reference, and deployment guide.
	•	src/ – Frontend code (HTML, CSS, JavaScript, assets).
	•	smart-contracts/ – Ethereum smart contracts for federated learning and model registry.
	•	backend/ – Node.js server, API routes, and database models.
	•	tests/ – Unit and integration tests for all components.
	•	deployment/ – Docker and Kubernetes configurations for scalable deployment.

Getting Started
	1.	Prerequisites: Node.js ≥18, npm/yarn, Docker, and an Ethereum testnet.
	2.	Installation: Clone repo, install dependencies, start the backend server.
	3.	Smart Contract Deployment: Compile contracts using Hardhat and deploy to a local or testnet blockchain.
